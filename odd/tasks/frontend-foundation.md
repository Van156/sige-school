## Objective

Standardize the web frontend on shadcn primitives in `packages/ui`, a small set of shared composed components, and a feature-based folder structure with lint-enforced import boundaries — with no behavior change to existing routes.

## Constraints

- No behavior change to any route in `auth-multitenant-rbac.md` §7 (F3.1).
- All base components come from the shadcn registry (style `base-lyra`); the shadcn `form` item is not used (TanStack Form → `field` + shared `FormField`).
- Inside a feature, imports are relative; `@/features/<name>` only across features and from routes (§4.6).
- oxlint boundary globs must use `@/features/*/**` (verified on oxlint 1.85.0; `*/*` does not match).
- Conventional commits, no AI attribution. Formatters run before commit so lefthook hooks are no-ops.
