# Feature: Storybook for Base UI Components

- **Spec:** `docs/specs/storybook.md` (source of truth for S0–S4)
- **Tracker branch:** `feat/storybook`, created from `feat/frontend-foundation-07-docs` (`5744130`) — frontend-foundation is not merged to `main` yet
- **Delivery:** strategy `ask-on-risk` → chain strategy `feature-branch-chain` (same as frontend-foundation): one slice branch per task `feat/storybook-NN-<name>` stacked on the previous slice
- **TDD:** on for pure logic — source: project convention (`odd/tasks/auth-multitenant-rbac.md`, user choice 2026-09-26) — runner: `bun test`. Applies to the coverage test (RED with missing stories → GREEN). Generated primitives, config, and stories use ordinary checks.
- **Review (RDD):** on (global default)
- **Forecast:** ~4,000–6,000 authored changed lines (≈55 story files; shadcn-generated primitives excluded) → 6 slices

## Objective

A Storybook in `packages/ui` that documents every base UI primitive (the full shadcn `ui` registry minus `form` and the AI chat items), in light and dark mode, with autodocs, an a11y check, and a test that makes a story mandatory for every primitive.

## Constraints

- Sequencing override: the spec says to start after frontend-foundation closes; the user asked to start now (2026-09-30). frontend-foundation T7 browser smoke is still pending.
- Storybook and addons are `devDependencies` of `packages/ui`; nothing ships in the web bundle.
- Stories import primitives as `@base-template/ui/components/<name>`; no `apps/web` imports (boundary rule `packages/ui/**`).
- New primitives via the shadcn CLI from `packages/ui` (`npx shadcn@4.21.0 add <name>`), never overwriting existing files; report manual edits.
- Deterministic fixtures only (no `Math.random`, no unfixed dates, no network).
- Toolchain risk §4.7: workspace overrides `vite` with `@voidzero-dev/vite-plus-core`; verify dev server + static build first; fallbacks in the spec order, then stop and report.
- Conventional commits, no AI attribution. Formatters run before commit so lefthook hooks are no-ops.
